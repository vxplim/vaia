# VAIA Progress

## How to run the app

1. Open Terminal (or Claude Code) in the `~/Projects/vaia` folder.
2. Type `npm run dev` and press Enter. (In Claude Code, type `! npm run dev`.)
3. The VAIA window opens. Quit it with **Cmd+Q**.

If you've just downloaded the code onto a new computer, run `npm install` once first.
